# Xcode Server, and what replaced it

Xcode Server (the "bots" in Xcode's Report navigator, hosted by macOS Server) was removed in
Xcode 13. Apple's replacement is **Xcode Cloud**. Both run the same thing: a shared Xcode
scheme's build and test actions. So the CI contract here is the scheme, not the server:

| Runner | How it runs `ProofSheet-iOS` / `ProofSheet-macOS` |
|---|---|
| Jenkins | `scripts/ci/ui.sh` → `xcodebuild test -scheme … -destination …` |
| GitHub Actions | the same script (`.github/workflows/ci.yml`) |
| Xcode Cloud | `ci_scripts/ci_post_clone.sh` generates the project, then a workflow runs the scheme's Test action |
| Xcode Server (Xcode 12 and earlier) | a bot on the same scheme: see `bot.md` |

The schemes are generated by XcodeGen from `App/project.yml` with `shared` schemes, which is what
both Xcode Server bots and Xcode Cloud workflows require (a user scheme is invisible to them).
